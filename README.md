# 📱 DayX - Aplicativo Android em Kotlin
DayX é um aplicativo Android desenvolvido em Kotlin que exibe diariamente uma lista de fatos e eventos históricos que aconteceram na data atual. O objetivo é oferecer uma forma simples e intuitiva de aprender algo novo todos os dias, explorando acontecimentos importantes da história mundial.

## ✨ Funcionalidades principais
- 📌 Eventos históricos do dia atual
- 🔄 Atualização automática a cada nova data
- 🔍 Interface simples e intuitiva
- 📜 Lista organizada com títulos e descrições dos eventos
- 🌐 Integração com API pública de eventos históricos (history.muffinlabs)

## 🛠️ Tecnologias utilizadas
- Kotlin
- Android Jetpack (ViewModel, StateFlow, Compose)
- Hilt – Framework de injeção de dependências para modularização e desacoplamento
- Room – Banco de dados local utilizado para cache dos eventos históricos
- DataStore – Persistência leve para armazenar a data da última atualização
- LazyColumn
- Consumo de API com Retrofit
- Arquitetura MVVM

## 🎯 Objetivo do projeto
O aplicativo foi desenvolvido com o intuito de praticar Kotlin e aprimorar habilidades no desenvolvimento Android moderno, aplicando boas práticas de arquitetura, organização de código e gerenciamento de dados. Durante o projeto, foram integrados recursos como consumo de API, injeção de dependências, persistência local e armazenamento de preferências, além do uso de padrões reativos para lidar com atualização de estados e exibição de listas dinâmicas. Em essência, este projeto serviu como um laboratório prático para consolidar o domínio das ferramentas e conceitos recomendados no desenvolvimento Android atual, produzindo uma solução funcional, escalável e bem estruturada.
